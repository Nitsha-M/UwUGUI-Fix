Наш сервер использует **Core Shaders** для создания различного уникального контента без внедрения сторонних модификаций. Однако, популярный мод [Iris Shaders](https://modrinth.com/mod/iris) не поддерживает их, ломая наш ресурс-пак при примененных шейдерах.

Для решения этой проблемы мы создали мод, добавляющий совместимость нашего пака с **Iris**. Мод не является обязательным к установке, если вы не пользуйтесь шейдерами на постоянной основе.
